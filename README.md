# Шахматный бот

Браузерное приложение: на стартовом экране нажмите «Играть», выберите цвет бота, затем указывайте ходы соперника, выбирая фигуру и клетку назначения. Кнопка «Выйти из игры» под доской возвращает в главное меню. Приложение не подключается к игровым сайтам.

Бот использует собственный поиск minimax с альфа-бета-отсечением, оценкой материала, развития фигур, пешечной структуры и безопасности короля. Иногда он может выбрать просчитанную жертву, только если найденное продолжение сохраняет явный перевес. Это экспериментальный движок, он слабее Stockfish и не гарантирует победу.

## Запуск

Нужен Python 3 и подключение к интернету для загрузки шахматной библиотеки и шрифта. В папке проекта выполните:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:8765>. Не открывайте `index.html` напрямую: браузер блокирует загрузку модулей и движка для `file://`.

## Android

Проект Android находится в папке `android/`. В приложении используется та же веб-версия, а присланное изображение установлено как значок. Для ходов и шрифта нужен интернет.

GitHub Actions собирает APK при отправке изменений в `main`/`master`. Готовый `app-debug.apk` доступен в артефактах запуска workflow. Чтобы создать GitHub Release с APK, опубликуйте тег вида `v1.0.0`.

Если бот играет белыми, он сделает первый ход сам. Если чёрными — первым ходит соперник, его ход нужно показать на доске. Пешка при превращении автоматически становится ферзём.

## Реализация

- [chess.js](https://github.com/jhlywa/chess.js) используется для проверки правил и генерации легальных ходов.
- [chess-engine.js](./chess-engine.js) содержит собственный поиск и позиционную оценку.
